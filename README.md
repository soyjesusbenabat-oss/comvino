# comvino.portalintracom.com

Web del I Congreso Internacional de Comunicación y Cultura del Vino (ComVino),
Villa de Teguise, Lanzarote, 27 a 30 de noviembre de 2026.

Sitio estático de una sola página, diseñado en Claude Design. `index.html` lleva el diseño y los
textos; `assets/` guarda las fotos e imágenes, traídas del WordPress anterior para no depender de él.
